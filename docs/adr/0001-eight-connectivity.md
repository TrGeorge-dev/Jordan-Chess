# 0001：连通性改为八连通

## 背景

旧规则（四连通：仅上下左右相邻视为连通）下，游戏严重偏向和棋：经典平局形态"黑白棋盘格填色"中同色棋子四连通下互不相邻、永不成环，双方可无限防守拖满棋盘。实测 AI 对 AI 在 10×10 上频繁满盘平局。

用户提出将"连通"改为八连通（斜向相邻也算连通）。审问确认：闭环定义为"顶点互异的八连通闭合折线，**允许斜边交叉**（X 形 4 子即闭环），至少 4 个顶点"，成环即胜的胜利条件不变。

## 决定

- 连通性判定从四连通改为**八连通**（上下左右 + 四个对角，切比雪夫距离 1）
- 闭环 = 八连通闭合折线：顶点互异、相邻顶点距离 1、**允许自交**、顶点数 ≥ 4
- 其他规则全部不变：成环即胜、悔棋、自定义棋盘大小（2~30）、人机执黑/执白
- AI（V3 默认 + Legacy/Threat 回归基准 + 网页版 JS）全部适配八连通

## 为什么

- 八连通下棋盘格填色的斜对角全是同色（(x+y) 奇偶性差 2），同色棋子必然连通成环——经典平局形态从数学上消失
- 防守维度从 4 方向扩大到 8 方向，更难封堵，对局更快出胜负
- 允许斜边交叉使检测无需交叉判定（顶点互异即闭环），实现简单

## Considered Options（被否决）

- **围棋气/提子机制**：曾提议引入"气 = 相邻空点数、气为 0 被提、提子即胜"，用户澄清并非此意——不是彻底围死，而是斜向连线也算连通。否决。
- **严格约当曲线（不自交）**：斜边交叉时（X 形）按严格约当曲线应无效，用户明确选择"交叉算有效闭环"。否决，规则与"约当曲线"名称存在语义偏差（名称保留，规则描述用"闭合折线"）。

## Consequences

- 环路检测无需斜边交叉检测（交叉合法）
- 邻居枚举从 4 方向扩为 8 方向：v 的邻居对从 C(4,2)=6 增至 C(8,2)=28，BFS 次数增加但棋盘小、可接受
- 环的最小形态：4 顶点（单位方格 / 斜菱形 / X 形）；3 顶点三角形**不算**环（保证"圈"有意义，避免 3 手速胜）
- AI 威胁体系（T1/T2/fork）定义不变，连通性判定平移为八连通
